# Шаг 09. Разбиваем книгу на параграфы

🎯 **Цель:** при создании книги передаём поле `content` — большой текст, который сервер разбивает на параграфы и сохраняет.

📁 **Файлы шага:**
- `src/main/java/com/lingua/api/service/BookService.java` (расширяем)
- `src/main/java/com/lingua/api/controller/BookController.java` (меняем `POST /books`)

## 1. Расширяем сервис

Открой `BookService.java`. Добавь поле `paragraphRepo`, новый метод `createBook` (с разбиением), и приватный helper `insertParagraphBatch`. Замени **весь** `createBook` на:

```java
package com.lingua.api.service;

import com.lingua.api.model.Book;
import com.lingua.api.model.Paragraph;
import com.lingua.api.repository.BookRepository;
import com.lingua.api.repository.ParagraphRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.Optional;

@Service
@RequiredArgsConstructor
public class BookService {

    private final BookRepository bookRepo;
    private final ParagraphRepository paragraphRepo;

    public List<Book> listBooks() {
        return bookRepo.findAllByOrderByCreatedAtAsc();
    }

    public Optional<Book> getBook(Integer id) {
        return bookRepo.findById(id);
    }

    @Transactional
    public Book createBook(String title, String author, String language, String content) {
        List<String> rawParagraphs = Arrays.stream(content.split("\n\n+"))
                .map(String::trim)
                .filter(p -> p.length() > 10)
                .toList();

        Book book = new Book();
        book.setTitle(title);
        book.setAuthor(author);
        book.setLanguage(language != null ? language : "en");
        book.setTotalParagraphs(rawParagraphs.size());
        book.setTranslatedParagraphs(0);
        book.setTranslationStatus("pending");
        bookRepo.save(book);

        insertParagraphBatch(book.getId(), rawParagraphs);
        return book;
    }

    private void insertParagraphBatch(Integer bookId, List<String> texts) {
        List<Paragraph> batch = new ArrayList<>();
        for (int i = 0; i < texts.size(); i++) {
            Paragraph p = new Paragraph();
            p.setBookId(bookId);
            p.setPosition(i);
            p.setOriginalText(texts.get(i));
            p.setTranslated(false);
            batch.add(p);
            if (batch.size() == 200) {
                paragraphRepo.saveAll(batch);
                batch.clear();
            }
        }
        if (!batch.isEmpty()) {
            paragraphRepo.saveAll(batch);
        }
    }
}
```

🧠 **Разбор главных моментов:**

### `@Transactional`

```java
@Transactional
public Book createBook(...) { ... }
```

**Самая важная аннотация в сервисах.** Весь метод выполняется в **одной транзакции БД**. Если в середине упадёт исключение — все изменения откатятся.

Без неё могло бы случиться:
1. Сохранили книгу → коммит.
2. Начали сохранять параграфы → ошибка.
3. В БД осталась книга-сирота без параграфов.

С `@Transactional`: или всё, или ничего.

### Stream API

```java
List<String> rawParagraphs = Arrays.stream(content.split("\n\n+"))
        .map(String::trim)
        .filter(p -> p.length() > 10)
        .toList();
```

Читается как пайплайн:
1. `content.split("\n\n+")` — разделить по пустым строкам, получить `String[]`.
2. `Arrays.stream(...)` — превратить массив в поток.
3. `.map(String::trim)` — для каждой строки убрать пробелы по краям.
4. `.filter(p -> p.length() > 10)` — оставить только длиннее 10 символов.
5. `.toList()` — собрать обратно в `List<String>`.

Аналог в JS: `arr.map(s => s.trim()).filter(s => s.length > 10)`.

### Батч-вставка

```java
if (batch.size() == 200) {
    paragraphRepo.saveAll(batch);
    batch.clear();
}
```

Книга может иметь 5000 параграфов. 5000 отдельных INSERT — медленно. Накапливаем по 200 и шлём пачками — в десятки раз быстрее.

## 2. Обновляем контроллер

В `BookController.java` замени метод `createBook` на:

```java
@PostMapping("/books")
public ResponseEntity<?> createBook(@RequestBody Map<String, Object> body) {
    String title = (String) body.get("title");
    String author = (String) body.get("author");
    String language = (String) body.get("language");
    String content = (String) body.get("content");

    if (title == null || title.isBlank()) {
        return ResponseEntity.badRequest().body(Map.of("error", "title is required"));
    }
    if (content == null || content.isBlank()) {
        return ResponseEntity.badRequest().body(Map.of("error", "content is required"));
    }

    Book book = bookService.createBook(title, author, language, content);
    return ResponseEntity.status(201).body(bookToMap(book));
}
```

## ✅ Проверка

Перезапусти сервер.

```bash
curl -X POST http://localhost:8080/books \
  -H 'Content-Type: application/json' \
  -d '{
    "title": "Hello World Book",
    "content": "First paragraph here, long enough.\n\nSecond paragraph also long enough to pass.\n\nThird one here."
  }'
```

```sql
SELECT id, title, total_paragraphs FROM books;

```
