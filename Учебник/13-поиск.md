# Шаг 13. Поиск по тексту

🎯 **Цель:** работает `GET /books/:id/search?q=word` — возвращает параграфы с этим словом.

📁 **Файлы шага:**
- `src/main/java/com/lingua/api/repository/ParagraphRepository.java` (добавляем `@Query`)
- `src/main/java/com/lingua/api/service/BookService.java` (добавляем `search`)
- `src/main/java/com/lingua/api/controller/BookController.java` (добавляем эндпоинт)

## 1. `@Query` в репозитории

Поиск по подстроке в двух колонках — это уже не просто derived query, нужен кастомный SQL.

В `ParagraphRepository.java` добавь импорт:
```java
import org.springframework.data.jpa.repository.Query;
```

И метод:

```java
@Query("SELECT p FROM Paragraph p WHERE p.bookId = :bookId AND " +
       "(LOWER(p.originalText) LIKE LOWER(CONCAT('%', :q, '%')) OR " +
       "LOWER(p.translatedText) LIKE LOWER(CONCAT('%', :q, '%'))) " +
       "ORDER BY p.position")
List<Paragraph> searchByBookId(Integer bookId, String q, Pageable pageable);
```

🧠 **Это JPQL** — язык запросов JPA, не SQL. Ключевое отличие:
- Используем имя **класса** `Paragraph`, не таблицы `paragraphs`.
- Используем имя **поля** `bookId`, не колонки `book_id`.

JPA сам переводит JPQL в SQL для нужной БД.

`:bookId`, `:q` — именованные параметры, подставятся из аргументов метода.

`Pageable` в конце даёт нам `LIMIT` бесплатно.

## 2. Метод сервиса

В `BookService.java`:

```java
public Map<String, Object> search(Integer bookId, String q, int limit) {
    PageRequest pr = PageRequest.of(0, limit);
    List<Paragraph> results = paragraphRepo.searchByBookId(bookId, q, pr);

    List<Map<String, Object>> items = results.stream().map(r -> {
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("id", r.getId());
        m.put("position", r.getPosition());
        m.put("originalText", r.getOriginalText());
        m.put("translatedText", r.getTranslatedText());
        m.put("isHeading", isHeading(r.getOriginalText()));
        return m;
    }).toList();

    Map<String, Object> result = new LinkedHashMap<>();
    result.put("results", items);
    result.put("total", items.size());
    result.put("query", q);
    return result;
}
```

🧠 **Что нового:**
- В каждый результат добавляем `isHeading: true/false` — клиент сможет показать заголовки иначе.

## 3. Эндпоинт

```java
@GetMapping("/books/{id}/search")
public ResponseEntity<?> search(
        @PathVariable Integer id,
        @RequestParam(required = false) String q,
        @RequestParam(defaultValue = "40") int limit) {
    if (q == null || q.isBlank()) {
        return ResponseEntity.badRequest().body(Map.of("error", "Missing query parameter q"));
    }
    if (bookService.getBook(id).isEmpty()) {
        return ResponseEntity.notFound().build();
    }
    limit = Math.min(80, Math.max(1, limit));
    return ResponseEntity.ok(bookService.search(id, q, limit));
}
```

🧠 `@RequestParam(required = false) String q` — если параметра нет, `q` будет `null` (не упадёт с ошибкой).

## ✅ Проверка

```bash
curl 'http://localhost:8080/books/6/search?q=para'
```

Должен вернуть параграфы, где встречается `para` (регистр игнорируем).

```bash
curl -i 'http://localhost:8080/books/6/search'
```

Без `q` — 400.
