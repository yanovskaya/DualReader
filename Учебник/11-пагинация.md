# Шаг 11. Пагинация параграфов

🎯 **Цель:** работает `GET /books/:id/paragraphs?page=1&pageSize=20` и возвращает страницы.

📁 **Файлы шага:**
- `src/main/java/com/lingua/api/repository/ParagraphRepository.java` (расширяем)
- `src/main/java/com/lingua/api/service/BookService.java` (добавляем метод)
- `src/main/java/com/lingua/api/controller/BookController.java` (добавляем эндпоинт)

## 1. Расширяем репозиторий

В `ParagraphRepository.java` добавь импорты:
```java
import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;
```

И **новый** метод (рядом с существующим `findByBookIdOrderByPosition(Integer)`):

```java
Page<Paragraph> findByBookIdOrderByPosition(Integer bookId, Pageable pageable);
```

🧠 **Магия Spring Data:**

- `Pageable` — спец-параметр (всегда последний). Spring сам добавит `LIMIT` и `OFFSET`.
- Возвращаемый `Page<T>` содержит и сами данные (`getContent()`), и метаинформацию (`getTotalElements()`, `getTotalPages()`).

> Заметила, что у нас два метода с одинаковым именем `findByBookIdOrderByPosition`? Это **перегрузка** методов: разные параметры → разные методы. Один без пагинации (вернёт всё), другой с `Pageable` (вернёт страницу).

## 2. Метод в сервисе

В `BookService.java` добавь импорты:
```java
import org.springframework.data.domain.Page;
import org.springframework.data.domain.PageRequest;
import java.util.LinkedHashMap;
import java.util.Map;
```

И метод:

```java
public Map<String, Object> getParagraphs(Integer bookId, int page, int pageSize) {
    long total = paragraphRepo.countByBookId(bookId);
    PageRequest pr = PageRequest.of(page - 1, pageSize);
    Page<Paragraph> pageResult = paragraphRepo.findByBookIdOrderByPosition(bookId, pr);

    List<Map<String, Object>> items = pageResult.getContent().stream()
            .map(this::paragraphToMap)
            .toList();

    Map<String, Object> result = new LinkedHashMap<>();
    result.put("paragraphs", items);
    result.put("total", total);
    result.put("page", page);
    result.put("pageSize", pageSize);
    result.put("totalPages", (int) Math.ceil((double) total / pageSize));
    return result;
}

public Map<String, Object> paragraphToMap(Paragraph p) {
    Map<String, Object> m = new LinkedHashMap<>();
    m.put("id", p.getId());
    m.put("bookId", p.getBookId());
    m.put("position", p.getPosition());
    m.put("originalText", p.getOriginalText());
    m.put("translatedText", p.getTranslatedText());
    m.put("isTranslated", p.isTranslated());
    return m;
}
```

🧠 **Тонкости:**

- В API страницы нумеруются **с 1** (привычно), а в `Pageable` — **с 0**. Поэтому `page - 1`.
- `(double) total / pageSize` — приведение к `double`, иначе будет целочисленное деление.
- `Math.ceil(...)` — округление вверх.
- `paragraphToMap` сделали `public`, чтобы переиспользовать из контроллера.

## 3. Эндпоинт в контроллере

В `BookController.java` добавь:

```java
@GetMapping("/books/{id}/paragraphs")
public ResponseEntity<?> getParagraphs(
        @PathVariable Integer id,
        @RequestParam(defaultValue = "1") int page,
        @RequestParam(defaultValue = "20") int pageSize) {
    if (bookService.getBook(id).isEmpty()) {
        return ResponseEntity.notFound().build();
    }
    page = Math.max(1, page);
    pageSize = Math.min(100, Math.max(1, pageSize));
    return ResponseEntity.ok(bookService.getParagraphs(id, page, pageSize));
}
```

🧠 **Разбор:**

- `@RequestParam(defaultValue = "1") int page` — query-параметр `?page=...`. Если не передан → `1`.
- Защита: `pageSize` зажимаем в [1; 100] — чтобы клиент не мог запросить 100000 параграфов разом.

## ✅ Проверка

Создай книгу с >5 параграфами:

```bash
curl -X POST http://localhost:8080/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"Big Book","content":"para 1 with enough text\n\npara 2 with enough text\n\npara 3 with enough text\n\npara 4 with enough text\n\npara 5 with enough text\n\npara 6 with enough text\n\npara 7 with enough text"}'
```

Запомни id, например 6.

```bash
curl 'http://localhost:8080/books/6/paragraphs?page=1&pageSize=3'
```

Ожидаем JSON с 3 параграфами и `"totalPages":3`.

```bash
curl 'http://localhost:8080/books/6/paragraphs?page=2&pageSize=3'
```

— параграфы 4-6.
