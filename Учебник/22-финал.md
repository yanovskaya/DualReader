## 1. CORS

Браузер по умолчанию **запрещает** JavaScript на одном домене делать запросы к другому. Чтобы фронтенд мог стучаться к нашему бэкенду — нужно явно разрешить через CORS.

**`src/main/java/com/lingua/api/config/CorsConfig.java`** (новый):

```java
package com.lingua.api.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.CorsRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
public class CorsConfig {

    @Bean
    public WebMvcConfigurer corsConfigurer() {
        return new WebMvcConfigurer() {
            @Override
            public void addCorsMappings(CorsRegistry registry) {
                registry.addMapping("/**")
                        .allowedOriginPatterns("*")
                        .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                        .allowedHeaders("*")
                        .allowCredentials(false);
            }
        };
    }
}
```

🧠 **Разбор:**

- `addMapping("/**")` — для всех путей.
- `allowedOriginPatterns("*")` — с любых доменов. Для продакшена лучше указать конкретные.
- `allowedMethods(...)` — какие HTTP-методы.
- `allowCredentials(false)` — без cookies (если `true` — нельзя `*` в origins).

## 2. Actuator (мониторинг)

В `pom.xml` добавь:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
```

В `application.properties`:

```properties
management.endpoints.web.base-path=/actuator
management.endpoint.health.enabled=true
```

🧠 **Это даёт `GET /actuator/health`** — стандартный эндпоинт для проверки «жив ли сервис». Используется в Kubernetes, Docker, на Replit и т.д.

## 3. Контекст-путь и логи

Если хочешь, чтобы все эндпоинты лежали под `/api/...`, в `application.properties` добавь:

```properties
server.servlet.context-path=/api
```

С этого момента `GET /healthz` станет `GET /api/healthz`. Удобно, если фронт и бэк на одном домене.

И уровень логов:

```properties
logging.level.com.lingua=INFO
logging.level.org.hibernate.SQL=WARN
```

## ✅ Финальная проверка

Перезапусти сервер. Если включила `context-path=/api`, все запросы теперь:

```bash
curl http://localhost:8080/api/healthz
curl http://localhost:8080/api/actuator/health
curl http://localhost:8080/api/books
```

Прогон по всем эндпоинтам:

```bash
# Здоровье
curl http://localhost:8080/api/healthz
curl http://localhost:8080/api/actuator/health

# Книги
curl http://localhost:8080/api/books
curl -X POST http://localhost:8080/api/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"Final","content":"first long enough\n\nsecond long enough\n\nchapter 1\n\nthird long enough"}'
curl http://localhost:8080/api/books/1/paragraphs
curl http://localhost:8080/api/books/1/chapters
curl 'http://localhost:8080/api/books/1/search?q=long'
curl http://localhost:8080/api/books/1/stats

# Перевод (нужен OPENAI_API_KEY)
curl -N -X POST http://localhost:8080/api/books/1/translate -H 'Content-Type: application/json'
curl http://localhost:8080/api/books/1/translation-status

# Словарь
curl 'http://localhost:8080/api/dictionary/lookup?word=resilient'
curl http://localhost:8080/api/dictionary/recent

# Загрузка
echo "para 1 long enough\n\npara 2 long enough" > /tmp/test.txt
curl -X POST http://localhost:8080/api/books/upload -F "file=@/tmp/test.txt"

# Удаление
curl -i -X DELETE http://localhost:8080/api/books/1
```

Все ответы должны быть осмысленными (200 / 201 / 204 / 400 / 404 в зависимости от ситуации).

## 🎓 Куда расти дальше

Теперь, когда ты понимаешь Spring Boot:

1. **Тестирование**: JUnit 5 + Mockito + `@SpringBootTest`. Очень важно.
2. **Безопасность**: Spring Security (JWT, OAuth, аутентификация).
3. **Валидация**: Bean Validation (`@Valid`, `@NotBlank`, `@Min`).
4. **Кэширование**: `@Cacheable`, Redis.
5. **Миграции БД**: Flyway или Liquibase (вместо ручного SQL).
6. **DTO и MapStruct**: вместо `Map<String, Object>`.
7. **OpenAPI**: автогенерация документации эндпоинтов через springdoc-openapi.
