# Глава 15. Глоссарий и что дальше

## Все аннотации, которые встретились

### Spring Core

| Аннотация | Где | Что делает |
|---|---|---|
| `@SpringBootApplication` | Главный класс | Включает автоконфигурацию + сканирование пакетов |
| `@Configuration` | Класс | Класс содержит `@Bean`-методы |
| `@Bean` | Метод в `@Configuration` | Возвращаемый объект становится бином |
| `@Component` | Класс | Сделать класс бином (общая аннотация) |
| `@Service` | Класс | Бин-сервис (бизнес-логика) |
| `@Repository` | Интерфейс/класс | Бин-репозиторий (доступ к данным) |
| `@Primary` | Бин | «Если бинов несколько — выбирай этот» |
| `@RequiredArgsConstructor` (Lombok) | Класс | Конструктор со всеми `final`-полями (для DI) |

### Spring Web (HTTP)

| Аннотация | Где | Что делает |
|---|---|---|
| `@RestController` | Класс | HTTP-контроллер, возвращающий JSON |
| `@RequestMapping("/path")` | Класс/метод | Базовый префикс пути |
| `@GetMapping("/path")` | Метод | Обработать `GET` |
| `@PostMapping("/path")` | Метод | Обработать `POST` |
| `@PutMapping`, `@DeleteMapping`, `@PatchMapping` | Метод | Соответствующие HTTP-методы |
| `@PathVariable` | Параметр метода | Взять значение из `{...}` в URL |
| `@RequestParam` | Параметр метода | Взять query-параметр `?key=value` |
| `@RequestBody` | Параметр метода | Распарсить JSON-тело в объект |

### Spring Async

| Аннотация | Где | Что делает |
|---|---|---|
| `@EnableAsync` | Главный класс | Включить поддержку `@Async` |
| `@Async` или `@Async("executorName")` | Метод сервиса | Запустить в фоновом потоке |

### JPA / Hibernate

| Аннотация | Где | Что делает |
|---|---|---|
| `@Entity` | Класс модели | JPA-сущность |
| `@Table(name="...")` | Класс модели | Имя таблицы в БД |
| `@Id` | Поле | Первичный ключ |
| `@GeneratedValue(strategy=...)` | Поле | Авто-генерация значения |
| `@Column(name="...", nullable=...)` | Поле | Описание колонки |
| `@Transactional` | Метод сервиса | Выполнить в одной транзакции БД |

### Spring Data JPA

| Что | Где | Что делает |
|---|---|---|
| `JpaRepository<Entity, IdType>` | Базовый интерфейс репозитория | Даёт `save`, `findById`, `findAll`, `deleteById`... |
| `@Query("...")` | Метод репозитория | Кастомный JPQL/SQL |
| `@Query(value="...", nativeQuery=true)` | Метод репозитория | Кастомный нативный SQL |
| Derived методы (`findByXxx`) | Метод репозитория | Spring сам генерирует запрос по имени |

### Lombok

| Аннотация | Что делает |
|---|---|
| `@Data` | Геттеры + сеттеры + equals + hashCode + toString |
| `@NoArgsConstructor` | Пустой конструктор |
| `@AllArgsConstructor` | Конструктор со всеми полями |
| `@RequiredArgsConstructor` | Конструктор с `final`-полями |
| `@Getter` / `@Setter` | Только геттеры или только сеттеры |
| `@Slf4j` | Создаёт переменную `log` для логирования |

## Полезные классы и приёмы

| Что | Зачем |
|---|---|
| `Optional<T>` | Безопасная работа с null. `.map()`, `.orElse()`, `.orElseThrow()`. |
| `Stream API` | Функциональная обработка коллекций (map/filter/reduce). |
| `record` | Короткое объявление immutable data-класса. |
| `try-with-resources` | Автозакрытие ресурсов (`try (var x = ...) { ... }`). |
| `Map.of(...)` | Быстро создать неизменяемую `Map`. |
| `LinkedHashMap` | `Map`, сохраняющая порядок ключей (важно для JSON-ответов). |
| `Pageable` / `PageRequest` | Пагинация в Spring Data. |
| `SseEmitter` | Server-Sent Events. |
| `MultipartFile` | Загруженный файл. |
| `JdbcTemplate` | Прямой доступ к БД, когда JPA не подходит. |
| `HttpClient` (Java 11+) | HTTP-вызовы без сторонних библиотек. |
| `ObjectMapper` (Jackson) | JSON ↔ объекты. |

## Чек-лист «как создать новый бэкенд с нуля»

1. **Создать проект** через https://start.spring.io: выбрать Maven, Java 17, добавить зависимости *Spring Web*, *Spring Data JPA*, *PostgreSQL Driver*, *Lombok*.
2. **Написать главный класс** с `@SpringBootApplication`.
3. **`application.properties`**: указать порт, контекст-путь, БД, лимиты.
4. **`config/`**: бин для DataSource, при необходимости — пул потоков, CORS.
5. **`model/`**: сущности с `@Entity`, `@Id`, `@Column`.
6. **`repository/`**: интерфейсы, наследующие `JpaRepository`.
7. **`service/`**: бизнес-логика, `@Service`, `@RequiredArgsConstructor`, `@Transactional` где нужно.
8. **`controller/`**: HTTP-эндпоинты, `@RestController`, валидация.
9. **Запустить и тестировать**: `mvn spring-boot:run`, проверить через `curl`.

## Что читать дальше

### Сразу после этого учебника

1. **Официальный гайд Spring** «Building a RESTful Web Service»:
   https://spring.io/guides/gs/rest-service/
   — те же концепции, но на их примере. Закрепит знания.

2. **Spring Boot Reference Documentation**:
   https://docs.spring.io/spring-boot/docs/current/reference/html/
   — справочник, не учебник. Используй как Google для конкретных вопросов.

3. **Baeldung** (https://www.baeldung.com/):
   — лучший сайт с практическими статьями про Spring. Если гуглишь «как сделать X в Spring» — почти всегда первая ссылка ведёт сюда.

### Углубление

4. **Книга**: Craig Walls, *Spring in Action* (6-е издание).
   — самый известный учебник по Spring. Читается легко.

5. **Spring Data JPA Reference**:
   https://docs.spring.io/spring-data/jpa/docs/current/reference/html/
   — особенно раздел «Defining Query Methods».

6. **Hibernate User Guide**:
   https://docs.jboss.org/hibernate/orm/current/userguide/html_single/Hibernate_User_Guide.html
   — глубокое погружение в JPA.

### Темы, не затронутые в учебнике

- **Тестирование**: JUnit 5 + Mockito + `@SpringBootTest`. Очень важная тема.
- **Безопасность**: Spring Security (аутентификация, JWT, OAuth).
- **Валидация**: Bean Validation (`@Valid`, `@NotBlank`, `@Min`).
- **Кэширование**: `@Cacheable`, Redis.
- **Очереди сообщений**: RabbitMQ, Kafka.
- **Миграции БД**: Flyway или Liquibase.
- **Метрики и трейсинг**: Spring Boot Actuator + Prometheus + Grafana.

## Главный совет

Самый быстрый путь научиться — **сделать своё**.

Возьми простую идею:
- список задач,
- дневник тренировок,
- учёт расходов,
- мини-блог,
- учётка тренировок Дуо.

Скопируй структуру нашего проекта (`config/`, `model/`, `repository/`, `service/`, `controller/`), и шаг за шагом повтори всё, что узнала, на своих сущностях.

Через 2–3 проекта Spring Boot перестанет казаться магией. Через 5 — будешь автоматически писать корректный код.

Удачи! 🌱
