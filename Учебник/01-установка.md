# Шаг 01. Установка инструментов

🎯 **Цель:** на твоём компьютере должны заработать команды `java`, `mvn` и `psql`.

## Что нужно

| Инструмент | Зачем | Версия |
|---|---|---|
| **Java JDK** | язык, на котором пишем | 17 или новее |
| **Maven** | менеджер зависимостей и сборщик | 3.6+ |
| **PostgreSQL** | база данных | 14+ |
| **curl** | проверять эндпоинты | любая |
| Редактор кода | писать код | VS Code или IntelliJ IDEA Community |

## Если ты в Replit

В этом проекте уже всё установлено. Проверь:

```bash
java --version    # должна быть 17+
mvn --version     # должна быть 3.6+
psql --version    # должна быть 14+
curl --version    # любая
```

Если что-то не находится — напиши в чат «доустанови `<имя>`», и я помогу.

## Если на своём компьютере

### macOS (через Homebrew)

```bash
brew install openjdk@17 maven postgresql@16
```

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install openjdk-17-jdk maven postgresql postgresql-contrib curl
```

### Windows

1. Java: https://adoptium.net/ — скачай Temurin 17 LTS, установщик.
2. Maven: https://maven.apache.org/download.cgi — распакуй, добавь `bin/` в `PATH`.
3. PostgreSQL: https://www.postgresql.org/download/windows/

После установки **обязательно перезапусти терминал** и проверь все четыре команды выше.

## Редактор кода

**VS Code** + расширение «Extension Pack for Java» — самый простой вариант.

**IntelliJ IDEA Community Edition** (бесплатная) — удобнее для Java, но тяжелее. Скачать: https://www.jetbrains.com/idea/download/

Любой подойдёт — выбирай тот, что уже стоит.

## Создаём папку проекта

Сделай папку, в которой будешь собирать своё приложение. **Не путай с готовым `artifacts/api-server/`!**

```bash
mkdir ~/my-lingua
cd ~/my-lingua
```

> Дальше я буду называть эту папку «корнем проекта».

## Типичные грабли

### `java: command not found` после установки

Перезапусти терминал. Если не помогло — переменная `PATH` не подхватила Java. На macOS добавь в `~/.zshrc`:
```bash
export PATH="/opt/homebrew/opt/openjdk@17/bin:$PATH"
```
На Linux:
```bash
export PATH="/usr/lib/jvm/java-17-openjdk-amd64/bin:$PATH"
```
На Windows — переустанови, отметив галочку «Add to PATH».

### `mvn` ругается «JAVA_HOME is not defined»

Maven хочет знать, где лежит Java. Узнай путь:
```bash
# macOS / Linux
/usr/libexec/java_home -v 17        # macOS
readlink -f $(which java) | sed 's|/bin/java||'   # Linux
```

И добавь в `~/.zshrc` или `~/.bashrc`:
```bash
export JAVA_HOME=/path/from/above
```

### `psql: connection refused`

Postgres не запущен. На macOS: `brew services start postgresql@16`. На Linux: `sudo systemctl start postgresql`.

### Какая у меня версия Java?

```bash
java -version
```

⚠️ Обрати внимание: `java -version` (один минус) и `java --version` (два минуса) работают по-разному. Если у тебя Java 8 — оба выведут что-то, но мы хотим **17+**.

## ✅ Проверка

Все четыре команды (`java`, `mvn`, `psql`, `curl`) должны выводить версию без ошибок. Если так — готова к следующему шагу.

## 🤔 Проверь себя

1. Чем JDK отличается от JRE и почему нам нужен именно JDK?
2. Зачем разработчику Maven, если у нас уже есть `javac`?
3. Что такое `PATH` и почему без него не работают команды?

<details>
<summary>Мини-упражнение: проверь окружение одной командой</summary>

Напиши однострочник, который выведет версии всех четырёх инструментов сразу:

```bash
for cmd in java mvn psql curl; do echo "--- $cmd ---"; $cmd --version 2>&1 | head -1; done
```

Если хотя бы одна строка содержит «not found» — этот инструмент не установлен.
</details>
