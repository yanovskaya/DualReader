# Глоссарий

Все важные слова и аннотации, встретившиеся в учебнике. Используй как шпаргалку.

## Термины

| Термин | Значение |
|---|---|
| **Bean** | Объект, которым управляет Spring (создаёт, держит у себя, отдаёт другим бинам). |
| **Контейнер (ApplicationContext)** | Внутренний «мешок» Spring со всеми бинами. |
| **DI (Dependency Injection)** | Spring сам подставляет нужные объекты в конструктор/поля. Тебе не нужно `new`. |
| **IoC (Inversion of Control)** | «Не ты вызываешь фреймворк, а фреймворк вызывает тебя». DI — частный случай. |
| **Entity** | Java-класс, отображённый на таблицу БД. |
| **Repository** | Прослойка для работы с БД. У нас — интерфейсы Spring Data JPA. |
| **Service** | Бизнес-логика. Между контроллером и репозиторием. |
| **Controller** | Принимает HTTP-запросы, отдаёт ответы. |
| **DTO (Data Transfer Object)** | Класс «только для передачи данных» (например, тело запроса/ответа). |
| **JPA** | Стандарт Java для работы с БД через объекты. Реализация — Hibernate. |
| **Hibernate** | Конкретная библиотека, реализующая JPA. Spring Boot использует её по умолчанию. |
| **JPQL** | Язык запросов JPA. Похож на SQL, но оперирует **классами** и **полями**, а не таблицами. |
| **Native query** | Запрос на «настоящем» SQL — для случаев, когда JPQL не хватает. |
| **HikariCP** | Пул соединений с БД. Spring Boot использует его по умолчанию. |
| **MultipartFile** | Spring-обёртка над загруженным файлом. |
| **SSE (Server-Sent Events)** | Однонаправленный поток событий «сервер → клиент» по HTTP. |
| **CORS** | Правила, разрешающие браузеру делать запросы с одного домена на другой. |
| **Maven** | Сборщик проектов и менеджер зависимостей для Java. |
| **Lombok** | Библиотека, генерирующая геттеры/сеттеры/конструкторы из аннотаций. |
| **MockMvc** | Инструмент для тестирования контроллеров без поднятия Tomcat. |
| **Mockito** | Библиотека для создания фейковых объектов в тестах. |

## Аннотации Spring (главные)

### Объявление бинов
| Аннотация | Где ставится | Что делает |
|---|---|---|
| `@SpringBootApplication` | Главный класс | Триггер автоконфигурации + сканирование пакета. |
| `@Component` | Класс | «Сделай меня бином». |
| `@Service` | Класс | То же, что `@Component`, но «семантически» — это сервис. |
| `@Repository` | Класс / интерфейс | То же + перевод исключений БД в Spring-овские. |
| `@RestController` | Класс | `@Controller` + `@ResponseBody` — все методы возвращают JSON. |
| `@Configuration` | Класс | Класс с настройками; внутри методы `@Bean`. |
| `@Bean` | Метод в `@Configuration` | «Возвращаемый объект — это бин». |

### HTTP-маршрутизация
| Аннотация | Что делает |
|---|---|
| `@RequestMapping("/path")` | Базовый префикс для класса (или метода). |
| `@GetMapping("/x")` | `GET /x`. |
| `@PostMapping("/x")` | `POST /x`. |
| `@PutMapping`, `@DeleteMapping`, `@PatchMapping` | Аналогично. |
| `@PathVariable` | Берём значение из URL: `/books/{id}`. |
| `@RequestParam` | Берём значение из query: `?q=...`. |
| `@RequestBody` | Тело запроса → Java-объект (через Jackson). |
| `@RequestPart` | Часть multipart/form-data. |

### Внедрение зависимостей
| Аннотация | Что делает |
|---|---|
| `@Autowired` | «Подставь сюда бин нужного типа». На полях — устаревший стиль. |
| `@RequiredArgsConstructor` (Lombok) | Генерирует конструктор для всех `final`-полей. Современный способ DI. |
| `@Value("${prop}")` | Внедрить значение из `application.properties`. |
| `@Qualifier("name")` | Если бинов одного типа несколько — выбрать конкретный. |

### JPA / БД
| Аннотация | Что делает |
|---|---|
| `@Entity` | «Этот класс отображается на таблицу». |
| `@Table(name="...")` | Имя таблицы. |
| `@Id` | Первичный ключ. |
| `@GeneratedValue(strategy=IDENTITY)` | ID генерирует БД. |
| `@Column(name="...", nullable=false)` | Настройки колонки. |
| `@Transactional` | Метод выполняется в одной транзакции. |
| `@Query("...")` | Кастомный JPQL/SQL. |

### Lombok
| Аннотация | Что делает |
|---|---|
| `@Data` | Геттеры + сеттеры + `equals`/`hashCode`/`toString`. |
| `@NoArgsConstructor` | Конструктор без параметров. |
| `@AllArgsConstructor` | Конструктор со всеми параметрами. |
| `@RequiredArgsConstructor` | Конструктор для `final`-полей. |
| `@Slf4j` | Поле `log` для логирования. |
| `@Builder` | Билдер-паттерн. |

### Асинхронность
| Аннотация | Что делает |
|---|---|
| `@EnableAsync` | Включить поддержку `@Async` (на классе с `@Configuration`). |
| `@Async` | Метод выполняется в отдельном потоке. |

### Тесты
| Аннотация | Что делает |
|---|---|
| `@SpringBootTest` | Поднять весь контекст для теста. |
| `@DataJpaTest` | Поднять только JPA-слой + H2 в памяти. |
| `@WebMvcTest` | Поднять только web-слой. |
| `@Mock` (Mockito) | Сделать фейковый объект. |
| `@InjectMocks` (Mockito) | Создать реальный объект и подставить в него моки. |
| `@Test` (JUnit) | «Это тестовый метод». |

## Полезные классы

| Класс | Зачем |
|---|---|
| `ResponseEntity<T>` | Ответ с телом + статусом + заголовками. |
| `Optional<T>` | «Может быть, а может и нет». |
| `Page<T>`, `Pageable`, `PageRequest` | Пагинация. |
| `JdbcTemplate` | Прямые SQL-запросы, в обход JPA. |
| `RestTemplate` / `WebClient` / `HttpClient` | HTTP-клиенты для вызова чужих API. |
| `SseEmitter` | Источник Server-Sent Events. |
| `MultipartFile` | Загруженный файл. |
| `Logger` (slf4j) | Логирование. |

## Команды Maven (шпаргалка)

```bash
mvn spring-boot:run     # Запустить приложение
mvn test                # Запустить тесты
mvn package             # Собрать JAR
mvn clean               # Удалить target/
mvn dependency:tree     # Показать дерево зависимостей
mvn -v                  # Версия Maven и Java
```

## Команды psql (шпаргалка)

```bash
psql $DATABASE_URL                    # Подключиться
\dt                                   # Список таблиц
\d books                              # Структура таблицы
SELECT * FROM books LIMIT 5;          # Запрос
\q                                    # Выйти
```

## Куда смотреть, когда не понимаешь

1. **Логи приложения** — последнее `Caused by:`.
2. **`show-sql`** — что улетело в БД.
3. **Этот глоссарий** — что значит аннотация.
4. **Сравни с готовым** `artifacts/api-server/`.
