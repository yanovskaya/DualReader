# Шаг 18. Фоновый перевод

🎯 **Цель:** работает `POST /books/:id/translate`. Запрос возвращается мгновенно, перевод идёт в фоне.

📁 **Файлы шага:**
- `src/main/java/com/lingua/api/LinguaApiApplication.java` (добавляем `@EnableAsync`)
- `src/main/java/com/lingua/api/config/AsyncConfig.java` (новый)
- `src/main/java/com/lingua/api/repository/ParagraphRepository.java` (метод)
- `src/main/java/com/lingua/api/service/TranslationService.java` (новый)
- `src/main/java/com/lingua/api/controller/BookController.java` (эндпоинт)

## Зачем

Перевод книги — медленно (минуты). Если делать в HTTP-потоке, клиент будет ждать и отвалится по таймауту. Решение — `@Async`: метод выполняется в **отдельном потоке**, HTTP-ответ возвращается мгновенно.

## 1. Включаем поддержку `@Async`

В `LinguaApiApplication.java` добавь импорт и аннотацию:

```java
import org.springframework.scheduling.annotation.EnableAsync;

@SpringBootApplication
@EnableAsync                     // ← добавить
public class LinguaApiApplication {
    ...
}
```

🧠 **Без `@EnableAsync`** аннотация `@Async` **молча игнорируется** — частая ошибка новичков.

## 2. Пул потоков для перевода

**`src/main/java/com/lingua/api/config/AsyncConfig.java`** (новый):

```java
package com.lingua.api.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.scheduling.concurrent.ThreadPoolTaskExecutor;

import java.util.concurrent.Executor;

@Configuration
public class AsyncConfig {

    @Bean(name = "translationExecutor")
    public Executor translationExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(4);
        executor.setMaxPoolSize(8);
        executor.setQueueCapacity(50);
        executor.setThreadNamePrefix("translation-");
        executor.initialize();
        return executor;
    }
}
```

🧠 **Параметры пула:**
- 4 потока всегда наготове.
- При нагрузке до 8.
- Если все заняты — копим до 50 задач в очереди.
- Имя бина — `translationExecutor` (понадобится в `@Async("translationExecutor")`).

## 3. Метод репозитория для непереведённых

В `ParagraphRepository.java` добавь:

```java
List<Paragraph> findByBookIdAndIsTranslatedFalseOrderByPosition(Integer bookId);
```

Spring сам сгенерирует `WHERE book_id = ? AND is_translated = false ORDER BY position`.

## 4. Сервис перевода

**`src/main/java/com/lingua/api/service/TranslationService.java`** (новый):

```java
package com.lingua.api.service;

import com.lingua.api.model.Book;
import com.lingua.api.model.Paragraph;
import com.lingua.api.repository.BookRepository;
import com.lingua.api.repository.ParagraphRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

@Service
@RequiredArgsConstructor
public class TranslationService {

    private final BookRepository bookRepo;
    private final ParagraphRepository paragraphRepo;
    private final OpenAiService openAi;

    @Async("translationExecutor")
    public void translateBook(Integer bookId, int batchSize) {
        Optional<Book> optBook = bookRepo.findById(bookId);
        if (optBook.isEmpty()) return;

        Book book = optBook.get();
        List<Paragraph> untranslated = paragraphRepo.findByBookIdAndIsTranslatedFalseOrderByPosition(bookId);
        if (untranslated.isEmpty()) return;

        book.setTranslationStatus("in_progress");
        bookRepo.save(book);

        int translated = book.getTranslatedParagraphs();

        for (int i = 0; i < untranslated.size(); i += batchSize) {
            List<Paragraph> batch = untranslated.subList(i, Math.min(i + batchSize, untranslated.size()));
            boolean isLast = (i + batchSize) >= untranslated.size();

            StringBuilder textsToTranslate = new StringBuilder();
            for (int j = 0; j < batch.size(); j++) {
                textsToTranslate.append("[").append(j + 1).append("] ").append(batch.get(j).getOriginalText());
                if (j < batch.size() - 1) textsToTranslate.append("\n\n");
            }

            List<Map<String, String>> messages = List.of(
                    Map.of("role", "system", "content",
                            "You are a literary translator. Translate the following English paragraphs into Russian. " +
                            "Each paragraph is numbered with [N]. " +
                            "Return ONLY the translated paragraphs in the same numbered format [N]."),
                    Map.of("role", "user", "content", textsToTranslate.toString())
            );

            String translationText = openAi.complete("gpt-4.1-mini", 8192, messages);

            Map<Integer, String> translationMap = new HashMap<>();
            for (String line : translationText.split("\n\n+")) {
                Matcher m = Pattern.compile("^\\[(\\d+)\\]\\s*([\\s\\S]+)").matcher(line.trim());
                if (m.find()) {
                    translationMap.put(Integer.parseInt(m.group(1)), m.group(2).trim());
                }
            }

            for (int j = 0; j < batch.size(); j++) {
                Paragraph paragraph = batch.get(j);
                String translation = translationMap.getOrDefault(j + 1, translationText);
                paragraph.setTranslatedText(translation);
                paragraph.setTranslated(true);
                paragraphRepo.save(paragraph);
                translated++;
            }

            book = bookRepo.findById(bookId).orElse(book);
            book.setTranslatedParagraphs(translated);
            book.setTranslationStatus(isLast ? "completed" : "in_progress");
            bookRepo.save(book);

            if (!isLast) {
                try { Thread.sleep(200); } catch (InterruptedException ignored) {}
            }
        }
    }
}
```

🧠 **Разбор:**

### `@Async("translationExecutor")`

«Запусти меня в фоне в указанном пуле». Метод возвращает `void` — это нормально для async (можно и `CompletableFuture`).

### Что делает алгоритм

1. Находит непереведённые параграфы.
2. Делит их на батчи по `batchSize`.
3. Каждый батч — нумерует (`[1]`, `[2]`, ...) и шлёт в OpenAI с инструкцией «верни в том же формате».
4. Парсит ответ → `Map<номер, перевод>`.
5. Сохраняет каждый абзац.
6. Обновляет статус книги.
7. Маленькая пауза (200 мс) — чтобы не упереться в OpenAI rate limit.

### Зачем нумеровать `[1]`, `[2]`, `[3]`

Можно было бы попросить LLM «верни 8 переводов через пустую строку». Но:

- LLM **может склеить** два коротких абзаца в один.
- Может **разбить** один длинный на два.
- Может вставить **лишнее объяснение** между абзацами.

И мы потеряем соответствие «оригинал → перевод» по позиции в массиве. С нумерацией мы **сами** знаем, какой перевод к какому абзацу относится — даже если порядок поплывёт.

### Регулярка ответа

```java
Matcher m = Pattern.compile("^\\[(\\d+)\\]\\s*([\\s\\S]+)").matcher(line.trim());
```

- `m.group(1)` — содержимое первой `(...)` — число `N`.
- `m.group(2)` — второй — сам перевод.
- `[\\s\\S]+` (а не `.+`) ловит и переносы строк — перевод может быть многострочным.

### Защита от плохого ответа

```java
String translation = translationMap.getOrDefault(j + 1, translationText);
```

Если LLM **полностью проигнорировал** формат `[N]` (вернул просто текст без скобок), `translationMap` будет пустой. В этом случае мы **подставим весь ответ как есть** в каждый абзац — это плохо, но всё лучше, чем `null` и упавший INSERT. Альтернатива — отметить абзац как «не переведён» и попробовать ещё раз. Можешь добавить это самостоятельно как улучшение.

## 5. Эндпоинт

В `BookController.java` добавь поле:
```java
private final TranslationService translationService;
```

И метод:

```java
@PostMapping("/books/{id}/translate")
public ResponseEntity<?> translate(
        @PathVariable Integer id,
        @RequestBody(required = false) Map<String, Object> body) {
    if (bookService.getBook(id).isEmpty()) {
        return ResponseEntity.notFound().build();
    }
    int batchSize = 8;
    if (body != null && body.get("batchSize") != null) {
        try { batchSize = Integer.parseInt(body.get("batchSize").toString()); } catch (Exception ignored) {}
    }
    translationService.translateBook(id, batchSize);
    return ResponseEntity.accepted().body(Map.of("message", "Translation started"));
}
```

🧠 **`ResponseEntity.accepted()`** = HTTP 202 Accepted — «принял запрос, обработка в процессе».

## ✅ Проверка

```bash
curl -X POST http://localhost:8080/books/6/translate -H 'Content-Type: application/json'
```

Должен **мгновенно** вернуться `{"message":"Translation started"}`.

curl http://localhost:8080/books/6/translation-status

SELECT id, position, translated_text FROM paragraphs WHERE book_id = 6 LIMIT 5;

— должны появиться переводы.
