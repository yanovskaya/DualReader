# Шаг 05. Подключаемся к БД

🎯 **Цель:** Java-приложение умеет подключаться к PostgreSQL и при старте видит её.

📁 **Файлы шага:**
- `pom.xml` — добавляем зависимости
- `src/main/resources/application.properties` — настройки JPA
- `src/main/java/com/lingua/api/config/DatabaseConfig.java` — пишем `DataSource` руками

## 1. Добавляем зависимости

Открой `pom.xml`. В секцию `<dependencies>` добавь:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
</dependency>
```

Должно встать после уже существующего `spring-boot-starter-web`.

🧠 **Зачем каждое:**

- **`spring-boot-starter-data-jpa`** — тянет JPA, Hibernate, Spring Data JPA, HikariCP (пул соединений).
- **`postgresql`** — JDBC-драйвер. `scope=runtime` значит «нужен только при запуске, не при компиляции».
- **`lombok`** — генератор кода: добавит за нас геттеры/сеттеры/конструкторы через аннотации.

В `<build>/<plugins>/<plugin>` (там где `spring-boot-maven-plugin`) добавь конфигурацию, чтобы Lombok не попадал в финальный JAR:

```xml
<plugin>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-maven-plugin</artifactId>
    <configuration>
        <excludes>
            <exclude>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok</artifactId>
            </exclude>
        </excludes>
    </configuration>
</plugin>
```

## 2. Настройки JPA

Открой `application.properties` и добавь:

```properties
spring.jpa.hibernate.ddl-auto=none
spring.jpa.show-sql=false
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.PostgreSQLDialect
spring.jpa.open-in-view=false
```

🧠 **Разбор:**

| Настройка | Что значит |
|---|---|
| `ddl-auto=none` | Hibernate **не** трогает таблицы. Мы создаём их вручную через SQL. В продакшене — обязательно `none`. |
| `show-sql=false` | не печатать каждый SQL в консоль (включишь, когда будешь отлаживать) |
| `hibernate.dialect=PostgreSQLDialect` | говорим Hibernate, что работаем с Postgres |
| `open-in-view=false` | не держать соединение с БД во время рендера ответа (источник медленных запросов) |

## 3. Подключаемся к БД

Spring Boot **обычно** сам создаёт `DataSource` из `spring.datasource.url`. Но `DATABASE_URL` приходит в формате `postgres://...`, а JDBC хочет `jdbc:postgresql://...`. Поэтому пишем свой `DataSource`-бин.

Создай папку:
```bash
mkdir -p src/main/java/com/lingua/api/config
```

И файл **`src/main/java/com/lingua/api/config/DatabaseConfig.java`**:

```java
package com.lingua.api.config;

import com.zaxxer.hikari.HikariConfig;
import com.zaxxer.hikari.HikariDataSource;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.context.annotation.Primary;

import javax.sql.DataSource;
import java.net.URI;

@Configuration
public class DatabaseConfig {

    @Bean
    @Primary
    public DataSource dataSource() throws Exception {
        String dbUrl = System.getenv("DATABASE_URL");
        if (dbUrl == null || dbUrl.isBlank()) {
            throw new IllegalStateException("DATABASE_URL environment variable is not set");
        }

        if (dbUrl.startsWith("postgres://") || dbUrl.startsWith("postgresql://")) {
            URI uri = new URI(dbUrl);
            String host = uri.getHost();
            int port = uri.getPort() > 0 ? uri.getPort() : 5432;
            String path = uri.getPath().replaceFirst("^/", "");
            String userInfo = uri.getUserInfo();
            String user = "";
            String password = "";
            if (userInfo != null) {
                String[] parts = userInfo.split(":", 2);
                user = parts[0];
                password = parts.length > 1 ? parts[1] : "";
            }
            dbUrl = String.format("jdbc:postgresql://%s:%d/%s", host, port, path);

            HikariConfig config = new HikariConfig();
            config.setJdbcUrl(dbUrl);
            config.setUsername(user);
            config.setPassword(password);
            config.setMaximumPoolSize(10);
            config.setConnectionTimeout(30000);
            return new HikariDataSource(config);
        }

        HikariConfig config = new HikariConfig();
        config.setJdbcUrl(dbUrl);
        config.setMaximumPoolSize(10);
        return new HikariDataSource(config);
    }
}
```

🧠 **Разбор:**

- `@Configuration` — «класс с настройками».
- `@Bean` — «метод производит бин». Spring вызовет его один раз и сохранит результат.
- `@Primary` — «если есть несколько `DataSource`, этот основной».
- `System.getenv("DATABASE_URL")` — читаем переменную окружения.
- Парсим URL стандартным `java.net.URI`, достаём хост/порт/юзера/пароль.
- Собираем JDBC-URL и кладём в `HikariConfig`.
- **HikariCP** — самый быстрый пул соединений на JVM. Открыть соединение медленно (50 мс), пул держит 10 готовых и переиспользует.

## ✅ Проверка

Запусти:
```bash
mvn spring-boot:run
```

В логах **должно быть**:
```
HikariPool-1 - Starting...
HikariPool-1 - Added connection org.postgresql.jdbc.PgConnection@...
HikariPool-1 - Start completed.
```

Если есть строки про HikariPool без ошибок — БД подключена. Если ошибка `DATABASE_URL is not set` — установи переменную и перезапусти.

Также эндпоинт `/healthz` должен по-прежнему работать:
```bash
curl http://localhost:8080/healthz
```
