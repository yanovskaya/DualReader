# Шаг 12. Главы и распознавание заголовков

🎯 **Цель:** работает `GET /books/:id/chapters` — возвращает список глав.

📁 **Файлы шага:**
- `src/main/java/com/lingua/api/service/BookService.java` (добавляем `isHeading` и `getChapters`)
- `src/main/java/com/lingua/api/controller/BookController.java` (добавляем эндпоинт)

## Идея

У книги нет явных «глав» в БД — есть только параграфы. Глава = параграф, который выглядит как заголовок (короткий, с цифрой, в верхнем регистре и т.п.).

## 1. Метод `isHeading`

В `BookService.java` добавь импорт:
```java
import java.util.regex.Pattern;
```

И **статический** метод (положи в конец класса):

```java
public static boolean isHeading(String text) {
    String t = text.trim();
    if (t.length() > 120) return false;
    if (Pattern.compile("^\\d+\\.\\s+\\S").matcher(t).find()) return true;
    if (Pattern.compile("^(chapter|part|section|prologue|epilogue|afterword|foreword|preface|act|scene|book)\\b", Pattern.CASE_INSENSITIVE).matcher(t).find()) return true;
    if (Pattern.compile("^[IVXLCDM]+\\.?\\s*$").matcher(t).matches()) return true;
    if (t.length() <= 60 && t.equals(t.toUpperCase()) && Pattern.compile("^[A-Z][A-Z\\s\\d'\"\\-]{2,}$").matcher(t).matches()) return true;
    return false;
}
```

🧠 **Алгоритм проверяет по очереди:**
1. Длиннее 120 символов — точно не заголовок.
2. Начинается с `1. Что-то` — заголовок.
3. Начинается с `Chapter`, `Part`, `Prologue` и т.д.
4. Это римская цифра отдельной строкой (`II`, `IV`).
5. Короткая строка ВСЯ В ВЕРХНЕМ РЕГИСТРЕ.

🧠 **Регулярки:**

- `Pattern.compile(regex)` — компилируем выражение.
- `.matcher(text)` — применяем к строке.
- `.find()` — найти где-то.
- `.matches()` — вся строка должна соответствовать.
- `Pattern.CASE_INSENSITIVE` — без учёта регистра.

## 2. Метод `getChapters`

В тот же файл добавь:

```java
public List<Map<String, Object>> getChapters(Integer bookId) {
    List<Paragraph> all = paragraphRepo.findByBookIdOrderByPosition(bookId);
    List<Paragraph> headings = all.stream().filter(p -> isHeading(p.getOriginalText())).toList();

    List<Map<String, Object>> chapters = new ArrayList<>();
    String prevText = null;
    for (Paragraph h : headings) {
        if (!h.getOriginalText().equals(prevText)) {
            Map<String, Object> ch = new LinkedHashMap<>();
            ch.put("id", h.getId());
            ch.put("position", h.getPosition());
            ch.put("originalText", h.getOriginalText());
            ch.put("translatedText", h.getTranslatedText());
            chapters.add(ch);
            prevText = h.getOriginalText();
        }
    }
    return chapters;
}
```

🧠 **Что делаем:**
1. Берём все параграфы книги.
2. Фильтруем только заголовки.
3. Убираем подряд идущие дубликаты (`if (!h.getOriginalText().equals(prevText))`) — иначе если в книге два «CHAPTER 1» подряд, попадёт оба раза.

## 3. Эндпоинт

В `BookController.java`:

```java
@GetMapping("/books/{id}/chapters")
public ResponseEntity<?> getChapters(@PathVariable Integer id) {
    if (bookService.getBook(id).isEmpty()) {
        return ResponseEntity.notFound().build();
    }
    return ResponseEntity.ok(Map.of("chapters", bookService.getChapters(id)));
}
```

## ✅ Проверка

Создай книгу с заголовками:

```bash
curl -X POST http://localhost:8080/books \
  -H 'Content-Type: application/json' \
  -d '{
    "title":"Book With Chapters",
    "content":"Chapter 1\n\nFirst chapter content here long enough\n\nChapter 2\n\nSecond chapter content\n\nMore text here long enough"
  }'
```

Запомни id, например 7. И:

```bash
curl http://localhost:8080/books/7/chapters
```

Ожидаем JSON с двумя главами: «Chapter 1» и «Chapter 2».
