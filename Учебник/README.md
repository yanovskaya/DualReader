# Учебник по бэкенду Lingua — собираем с нуля

Привет! Этот учебник — **пошаговая инструкция**. После каждого шага у тебя на компьютере будет рабочий кусок приложения, который можно запустить и проверить через `curl`. К концу 22-го шага получится **тот же бэкенд**, что лежит в `artifacts/api-server/`.

## Главные правила

1. **Не пропускай шаги.** Каждый опирается на предыдущий.
2. **Не копируй вслепую.** Перед тем как вставить код — прочитай разбор «зачем».
3. **Проверяй после каждого шага.** В конце каждой главы есть команда для проверки. Если она не работает — НЕ ИДИ ДАЛЬШЕ, разбирайся.
4. **Папка для тренировки.** Создай отдельную папку, например `~/lingua-tutorial/api-server/`, и собирай там. Не путай с готовым `artifacts/api-server/` — это образец.
5. **Если застряла** — открой соответствующий файл в `artifacts/api-server/` и сравни.

## Как читать каждую главу

В каждом шаге будет:
- 🎯 **Цель** — что должно работать после этого шага.
- 📁 **Файлы** — какие файлы создаём/меняем.
- 📝 **Код** — что внутри написать.
- 🧠 **Разбор** — что и почему.
- ✅ **Проверка** — какую команду выполнить, чтобы убедиться.
- ➡️ **Дальше** — переход к следующему шагу.
