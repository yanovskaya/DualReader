# Учебник по бэкенду Lingua

Привет! Этот учебник проведёт тебя через **весь код бэкенда** — от пустой папки до работающего сервера. Никакого предварительного знания Java или Spring не требуется. Каждая глава короткая (10–15 минут чтения), в конце есть **контрольные вопросы** и **мини-упражнения**.

## Как читать

- Главы идут по порядку — **не пропускай**, каждая опирается на предыдущую.
- Открывай в соседнем окне реальный файл бэкенда (путь указан в начале каждой главы) и сверяйся.
- Если что-то непонятно — не пытайся всё запомнить с первого раза. Возвращайся.
- В конце каждой главы есть короткое задание. Делай его — без практики ничего не закрепится.
