# Шаг 04. PostgreSQL и схема таблиц

🎯 **Цель:** есть БД с таблицами `books` и `paragraphs`, и переменная `DATABASE_URL`.

📁 **Файлы шага:** только SQL-команды.

## Создаём базу

### В Replit

База уже создана автоматически, переменная `DATABASE_URL` установлена. Проверь:

```bash
echo $DATABASE_URL
```

Должна вывести что-то вроде `postgres://user:pass@host:5432/dbname`.

### На своём компьютере

```bash
sudo -u postgres psql
```

В psql:
```sql
CREATE DATABASE lingua;
CREATE USER lingua_user WITH PASSWORD 'secret';
GRANT ALL PRIVILEGES ON DATABASE lingua TO lingua_user;
\q
```

Установи переменную окружения (в `~/.bashrc` или `~/.zshrc`):
```bash
export DATABASE_URL="postgres://lingua_user:secret@localhost:5432/lingua"
```

## Создаём таблицы

Подключись к БД:

```bash
psql $DATABASE_URL
```

И выполни:

```sql
-- Тип статуса перевода (enum)
CREATE TYPE translation_status AS ENUM ('pending', 'in_progress', 'completed', 'failed');

-- Таблица книг
CREATE TABLE books (
    id SERIAL PRIMARY KEY,
    title TEXT NOT NULL,
    author TEXT,
    language TEXT NOT NULL DEFAULT 'en',
    total_paragraphs INTEGER NOT NULL DEFAULT 0,
    translated_paragraphs INTEGER NOT NULL DEFAULT 0,
    translation_status translation_status NOT NULL DEFAULT 'pending',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Таблица параграфов
CREATE TABLE paragraphs (
    id SERIAL PRIMARY KEY,
    book_id INTEGER NOT NULL REFERENCES books(id) ON DELETE CASCADE,
    position INTEGER NOT NULL,
    original_text TEXT NOT NULL,
    translated_text TEXT,
    is_translated BOOLEAN NOT NULL DEFAULT FALSE
);

CREATE INDEX idx_paragraphs_book_id ON paragraphs(book_id);
CREATE INDEX idx_paragraphs_position ON paragraphs(book_id, position);
```

🧠 **Разбор:**

| Конструкция | Что значит |
|---|---|
| `SERIAL PRIMARY KEY` | автоинкрементное целочисленное поле, первичный ключ |
| `TEXT` | строка любой длины (предпочтительнее `VARCHAR(N)` в PostgreSQL) |
| `TIMESTAMPTZ` | дата+время с часовым поясом (UTC) |
| `CREATE TYPE ... AS ENUM` | свой строгий тип-перечисление |
| `REFERENCES books(id) ON DELETE CASCADE` | внешний ключ. Если книгу удалят — все её параграфы тоже |
| `CREATE INDEX` | индекс — ускоряет поиск по этим колонкам |

## ✅ Проверка

В psql:

```sql
\dt
```

Должно вывести:
```
 public | books      | table | ...
 public | paragraphs | table | ...
```

И:
```sql
INSERT INTO books (title) VALUES ('Test');
SELECT * FROM books;
DELETE FROM books;
```

Если работает — таблицы готовы. Выйди из psql:
```sql
\q
```

## 🤔 Проверь себя

  1. Зачем нужны индексы и почему мы создали индекс на `book_id` в таблице `paragraphs`?
  2. Что делает `ON DELETE CASCADE` у внешнего ключа?
  3. Почему `translation_status` мы сделали `ENUM`, а не `VARCHAR`?

  <details>
  <summary>Мини-упражнение: посчитай книги без параграфов</summary>

  Напиши SQL-запрос, который вернёт книги, у которых нет ни одного параграфа:

  ```sql
  SELECT b.id, b.title
  FROM books b
  LEFT JOIN paragraphs p ON p.book_id = b.id
  WHERE p.id IS NULL;
  ```
