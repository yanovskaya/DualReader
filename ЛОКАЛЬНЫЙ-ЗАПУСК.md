# Локальный запуск Lingua

Инструкция для запуска проекта на своём компьютере (Windows / macOS / Linux).

---

## Требования

| Инструмент | Версия | Где взять |
|---|---|---|
| Java | 17+ | [adoptium.net](https://adoptium.net) — Temurin 17 |
| Maven | 3.8+ | [maven.apache.org/download](https://maven.apache.org/download.cgi) |
| Node.js | 18+ | [nodejs.org](https://nodejs.org) |
| pnpm | 8+ | `npm install -g pnpm` |

Проверить после установки:
```bash
java -version
mvn -version
node -version
pnpm -version
```

---

## Шаг 1 — Получить проект

```bash
git clone <ссылка на репозиторий>
cd DualReader
```

Если уже скачан — обновить:
```bash
git pull
```

> **Важно:** папку `node_modules` никогда не копируй между компьютерами — она привязана к операционной системе.

## Шаг 3 — База данных PostgreSQL

Бэкенд требует PostgreSQL. Проще всего завести бесплатную облачную БД на [Neon.tech](https://neon.tech):

1. Зарегистрироваться и создать проект.
2. Скопировать строку подключения вида:
   ```
   postgresql://user:password@host/dbname?sslmode=require
   ```

### Создать таблицы

В SQL Editor на Neon (или любом psql-клиенте) выполнить:

```sql
CREATE TABLE books (
    id SERIAL PRIMARY KEY,
    title TEXT NOT NULL,
    author TEXT,
    language TEXT NOT NULL DEFAULT 'en',
    total_paragraphs INTEGER NOT NULL DEFAULT 0,
    translated_paragraphs INTEGER NOT NULL DEFAULT 0,
    translation_status TEXT NOT NULL DEFAULT 'pending',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE paragraphs (
    id SERIAL PRIMARY KEY,
    book_id INTEGER NOT NULL REFERENCES books(id) ON DELETE CASCADE,
    position INTEGER NOT NULL,
    original_text TEXT NOT NULL,
    translated_text TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_paragraphs_book_id ON paragraphs(book_id);
CREATE INDEX idx_paragraphs_position ON paragraphs(book_id, position);

CREATE TABLE dictionary_lookups (
    id SERIAL PRIMARY KEY,
    word TEXT NOT NULL,
    translations TEXT[] NOT NULL,
    synonyms TEXT[],
    part_of_speech TEXT,
    transcription TEXT,
    examples TEXT[],
    example_translations TEXT[],
    looked_up_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_dictionary_word ON dictionary_lookups(word);
CREATE INDEX idx_dictionary_looked_up_at ON dictionary_lookups(looked_up_at DESC);
```

## Шаг 4 — Запустить бэкенд

**Windows (PowerShell):**
```powershell
$env:DATABASE_URL="postgresql://user:password@host/dbname?sslmode=require"
cd artifacts/api-server
mvn spring-boot:run
```

**macOS / Linux:**
```bash
export DATABASE_URL="postgresql://user:password@host/dbname?sslmode=require"
cd artifacts/api-server
mvn spring-boot:run
```

Через 10–20 секунд сервер запустится на `http://localhost:8080`. Проверить:
```bash
curl http://localhost:8080/api/healthz
# → {"status":"ok"}
```

> Чтобы не вводить `DATABASE_URL` каждый раз, добавь его в системные переменные окружения Windows (Параметры → Переменные среды) или в `~/.zshrc` / `~/.bashrc` на macOS/Linux.

## Шаг 5 — Запустить фронтенд

В **отдельном** терминале, из корня проекта:

```bash
pnpm --filter @workspace/bilingual-reader run dev
```

Открыть в браузере: **http://localhost:3000**

## Часто возникающие проблемы

### `lightningcss` / `esbuild` — ошибка про другую платформу

Папка `node_modules` была создана на другой ОС. Удали её и переустанови:

```bash
# Windows (PowerShell)
rmdir /s /q node_modules

# macOS / Linux
rm -rf node_modules

# Затем
pnpm install
```

### `DATABASE_URL environment variable is not set`

Переменная окружения не передана. Убедись, что задаёшь её **в том же окне терминала**, где запускаешь `mvn spring-boot:run`.

### Порт 8080 занят

```bash
# macOS / Linux
lsof -ti:8080 | xargs kill -9

# Windows (PowerShell)
Get-Process -Id (Get-NetTCPConnection -LocalPort 8080).OwningProcess | Stop-Process
```
